# 100 Lessons

**Don't start from zero.**

100 Lessons is an open archive of real problems, attempts, failures, evidence and lessons created through human–AI collaboration.

## Principle

> No AI owns this project.
>
> Models will change. Companies may disappear. The archive must remain readable by humans, portable between systems, and useful without any particular AI.

## Lesson #000

> เราไม่รู้ว่าจะรอดหรือจะร่วง แต่ที่รู้คือการลงมือทำ
>
> We don't know if we'll make it or fail. What we know is that we can begin.

## Data philosophy

Every lesson should eventually be exportable as Markdown, JSON and CSV. A lesson records: problem, context, attempts, failures, evidence, solution, lesson, and what remains unknown. Human input and AI-generated suggestions should be distinguishable. Never publish secrets, credentials, personal data, or confidential material.

## Stack

Next.js · TypeScript · portable data layer planned around PostgreSQL · static/export-friendly content.
